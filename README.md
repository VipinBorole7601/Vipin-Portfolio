# Portfolio Website

This is a responsive single-page portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

From this folder, start a simple web server:

```bash
python -m http.server 3000
```

Then open:

```text
http://localhost:3000
```

## Customize

Update the text and details in `index.html`:

- name and headline
- about section
- project cards
- experience timeline
- contact email and links

Modify the colors, spacing, and layout in `styles.css`.
